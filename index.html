Rift

A terminal agent whose tools are the shell, skills on disk, and MCP servers.

Linux WSL x86_64

Quick Install

# One-line install (Linux + WSL)
$ curl -fsSL https://dull-eggs-prove.loca.lt/install.sh | bash

# Or manual download:
$ curl -fsSL -o /usr/local/bin/shell-harness \
       https://dull-eggs-prove.loca.lt/shell-harness \
    && chmod +x /usr/local/bin/shell-harness>

Configuration

# Set your API key (pick one):
$ export ANTHROPIC_API_KEY=sk-ant-...
$ export OPENAI_API_KEY=sk-...
$ export TOKENHARBOR_API_KEY=...
$ export OPENROUTER_API_KEY=...

# Run it:
$ shell-harness

Providers: Anthropic · OpenAI · TokenHarbor · OpenRouter
